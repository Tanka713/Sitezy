Palette

Dark materials, controlled contrast, focused accent energy.

Sitezy should feel cinematic and digital, but never neon-heavy or noisy. Most surfaces stay neutral so the accent can do real work when something is selected, active, or meant to lead the eye.

Marketing System

Show the product. Keep the message short.

Hero blocks

Use big type, quiet copy, and product frames with one accent area doing most of the visual work.

Comparison cards

Show generic output versus directed output without sounding defensive or overly technical.

Proof modules

Guidelines

Light mode should translate the hierarchy, not reset the brand.

Light translation

Keep the accent. Lift the surfaces.

Light mode should stay crisp and premium. The background becomes soft, the surface becomes white, and the accent remains the same so the brand still reads as Sitezy.

Do

Use motion to reveal structure, reward selection, and confirm user direction.

Do not

Flood the UI with gradients, noisy blur, or oversized glows that flatten hierarchy.

Rule

If a component feels like every other AI startup, simplify it and sharpen the idea.
