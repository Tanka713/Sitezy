# Sitezy Media Pack

This folder contains a first-pass brand asset package for Sitezy based on the brand system in this thread.

Contents:

- `logo-concepts/`
  - three SVG concept boards exploring different premium logo directions
- `social-media-identity-kit/`
  - reusable SVG templates for square, carousel, story, and link-preview posts
- `ui-component-style-guide/`
  - a local HTML/CSS style guide showing core UI tokens and branded components
- `icon-style-system/`
  - a starter icon system spec plus matching SVG icons

Recommended review order:

1. Start with `logo-concepts/README.md`.
2. Review the social templates for tone and composition.
3. Open `ui-component-style-guide/index.html` in a browser for the strongest product-facing view.
4. Review the icon sheet and icon spec last.

Notes:

- These are concept-stage brand assets, not final production exports.
- SVG files remain editable in Figma, Sketch, Illustrator, or VS Code.
- The package is intentionally dark-first, with restrained blue/violet accents to match the Sitezy direction.
