# Sitezy Social Media Identity Kit

This kit is built for a sharp, design-literate social presence.

Goals:

- make Sitezy feel premium, not loud
- make the product UI feel like the hero
- keep copy short, visual, and confident
- avoid generic AI-builder aesthetics

Included templates:

- `social-square-launch.svg`
  - Instagram, LinkedIn, X image post, announcement card
- `social-carousel-cover.svg`
  - Instagram carousel cover or vertical post
- `social-story-template.svg`
  - Story, Reel cover, or mobile ad concept
- `social-link-card.svg`
  - Open Graph, X summary image, press/share link card

Usage rules:

- Keep backgrounds mostly dark.
- Use the blue/violet accent as a highlight, not the entire palette.
- Prioritize one strong line over long explanatory copy.
- Show product UI frames where possible.
- Keep safe margins generous:
  - square: `72px`
  - carousel vertical: `88px`
  - story: `96px`
  - link card: `60px`

Headline patterns that fit Sitezy:

- `Create a site that looks designed, not just generated.`
- `AI website creation with more taste and more control.`
- `Most AI websites look generated. Yours should not.`
- `Direction first. Website second.`

Suggested content lanes:

1. Before/after transformations
2. Direction or vibe-led prompts
3. Product workflow clips
4. Founder launch narratives
5. Editor feature spotlights
