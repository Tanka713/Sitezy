# Sitezy Logo Concepts

These concepts all keep the same strategic intent:

- premium, design-forward software
- direction over templates
- intelligent but not gimmicky
- controlled, cinematic, modern

Concepts:

1. `concept-01-directed-wordmark.svg`
   - strongest wordmark-led route
   - expresses motion, guidance, and premium product confidence
2. `concept-02-frame-spark.svg`
   - most explicit "website canvas + intelligence" route
   - strongest candidate for symbol-first usage
3. `concept-03-modular-s.svg`
   - most ownable monogram route
   - feels closest to a creative software mark

Recommendation:

- If Sitezy wants the clearest launch identity, start from Concept 01.
- If Sitezy wants the cleanest app icon potential, start from Concept 02.
- If Sitezy wants the most distinctive long-term brand mark, refine Concept 03.
