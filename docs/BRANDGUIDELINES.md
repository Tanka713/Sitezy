 10. Color System

 Recommended Core Direction

A premium darkfirst identity with sharp contrast and a controlled accent.

 Primary Palette

 Ink Black

0B0D12
Main dark background. Deep, clean, premium.

 Soft Graphite

151922
Secondary surfaces.

 Cloud White

F5F7FB
Main light text / light UI surfaces.

 Steel Mist

97A3B6
Muted copy and support text.

 Electric Blue

5B8CFF
Primary accent. Feels precise, digital, modern.

 Violet Pulse

7A5CFF
Secondary accent for gradients and depth.

 Mint Signal

37E6B5
Success / live / active states.

 Accent Gradient

5B8CFF → 7A5CFF
Use for focused emphasis, selected states, CTA glow, and premium depth.

 Color Behavior

 Keep backgrounds mostly dark or neutral.
 Use accent colors as controlled highlights, not everywhere.
 Avoid rainbow gradients and overly saturated neon overload.
 Let whitespace and contrast create premium feel.

 Light Mode Translation

If light mode is used:

 background becomes F7F8FC
 surface becomes FFFFFF
 text becomes 111827
 accent stays blue/violet

 12. Logo Direction

 Brand Logic

The Sitezy logo should feel like a mark for a modern creative software product, not a cartoon app.

 Recommended Logo Direction

 Wordmark First

A clean custom wordmark is the strongest primary identity.

 Logo Style Traits

 geometric but not stiff
 smooth modern letterforms
 subtle uniqueness in S, t, or z
 strong spacing
 confident at small sizes

 Symbol Options

 Option A: Direction Mark

A minimal abstract symbol inspired by:

 cursor movement
 layout framing
 a directed path
 a guiding spark

 Option B: Monogram

A clean S symbol built from modular layout lines or panels.

 Option C: Frame + Spark

A structured square/frame representing the website canvas, with one unexpected angled cut or signal line to suggest intelligence and direction.

 Logo Guidance

 keep it simple
 avoid obvious robot symbols
 avoid magic wand clichés
 avoid browserwindow clichés unless abstracted elegantly
 avoid playful startup mascots
