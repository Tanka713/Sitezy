Design **Sitezy** as a premium creative software product.

## Mission
Create UI that is:
- Premium
- Minimal
- Modern
- Intentional
- Visually distinct
- Non-generic

## Product Identity
Sitezy should feel like:
- A design tool, not a SaaS dashboard
- A creative platform, not an AI template generator
- A product with taste

Avoid:
- Generic AI startup design
- Bland SaaS layouts
- Template-like UI
- Overdecorated or noisy interfaces

## Engineering Alignment
Design must:
- Respect existing architecture
- Not break functionality
- Be realistically implementable
- Avoid fake or non-working UI
- Align with **sitezy-engineering**

## Design Thinking
Before coding:
- Identify screen purpose (editor, dashboard, etc.)
- Understand user state (creating, editing, managing)
- Define clear hierarchy
- Choose a precise visual direction

## Core Aesthetic Rules

### Typography
- Use refined modern fonts (Satoshi, General Sans, Neue Montreal, etc.)
- Strong hierarchy
- Avoid generic system fonts

### Color
- Dark or neutral base
- Controlled accent usage
- Avoid excessive gradients or glow
- Use variables for consistency

### Layout
- Strong spacing
- Clear hierarchy
- Avoid clutter
- Prioritize main content (especially editor canvas)

### Motion
- Smooth and minimal
- Used for clarity, not decoration
- Avoid flashy or noisy animations

### Surfaces
- Layered depth
- Subtle borders and contrast
- No flat emptiness or visual chaos

## Product-Specific Rules

### Landing Page
- Bold, product-led
- Strong hierarchy
- Avoid generic section stacking

### Dashboard
- Calm and structured
- Highlight key actions
- Avoid admin-panel clutter

### Generator
- Feels like creative direction
- Not a boring form

### Editor
- Canvas is the focus
- Controls are minimal but powerful
- Interaction clarity is critical

### Auth / Settings / Billing
- Must still feel premium
- No default template UI

## Component Rules

Buttons:
- Clear hierarchy
- Strong primary actions
- Clean states

Inputs:
- Refined and readable
- Strong focus states

Cards:
- Clean, minimal, well-spaced
- Avoid generic SaaS look

Modals:
- Fully designed
- Never default browser style

Sidebars:
- Structured, minimal
- No clutter

## Forbidden Patterns
- Purple AI gradients everywhere
- Default dashboard kits
- Weak spacing
- Random colors
- Cheap glassmorphism
- Template-like sections

## Implementation Rules
- Use reusable design tokens
- Maintain spacing, radius, and type consistency
- Ensure all components feel native to Sitezy
- Code must be real and production-ready

## Response Focus
- Prioritize visual clarity and polish
- Keep UI clean and intentional
- Avoid unnecessary complexity

## Final Rule
When in doubt:
Choose the more refined, minimal, and premium solution.
